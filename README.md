# Bulk Mockup

Batch Photoshop mockup generator for print-on-demand, Etsy, and Shopify sellers.

## Quick Start

1. Download src/bulk-mockup.jsx
2. Photoshop -> File -> Scripts -> Browse -> select script
3. Select template PSD + design folder + output folder
4. Click Run
